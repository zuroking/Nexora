# Keyboard navigation

Shortcuts are owned by `CommandId`: `Ctrl+P`, `Ctrl+N`, `Ctrl+Shift+N`,
`Ctrl+F`, `Ctrl+O`, `Ctrl+Shift+O`, `Ctrl+E`, `F2`, `Ctrl+W`. Tab/Enter in
autocomplete inserts the selected target; Escape dismisses popups. Every modal
has Cancel and an explicit confirm path. No hidden key handlers in widgets.
