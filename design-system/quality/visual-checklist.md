# Visual checklist

- [ ] No default egui blue in panels, tabs or selection.
- [ ] Type sizes match the scale; metadata 12 px muted.
- [ ] Sidebar rows show title + muted path, not just a filename.
- [ ] Source/Reading toggles with Ctrl+E and the mouse.
- [ ] Reading view renders lists, tasks, quotes, code and links.
- [ ] Status bar shows save state, snapshot count and word count.
- [ ] All OpenUrl commands intercepted; external URLs blocked.
- [ ] Contrast >= 4.5:1 in all three presets (`tests/theme.rs`).
- [ ] Screenshot captured after the change (`tools/visual-smoke.ps1`).
