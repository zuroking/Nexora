# Navigation

All actions live in the single `CommandId` registry; palette and keyboard share
it. `Ctrl+P` commands, `Ctrl+O` quick open, `Ctrl+Shift+O` outline, `Ctrl+E`
view toggle, `F2` rename. Ctrl+Click on a rendered wikilink follows the same
navigation path as Source mode. Anchored links open Source mode at the target
line (deliberate deviation, §38).
